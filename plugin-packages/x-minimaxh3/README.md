# X-MiniMaxH3 私有服务

把腾讯云 GPU 服务器上自建的 X-MiniMaxH3 接入影策：模型提交后进入 H3 Scheduler 队列，由调度器在资源安全时切换到 `first_last` 或 `reference` 引擎执行。

## 渠道配置

- Base URL：`http://152.136.42.128:8190`（插件已内置，填写渠道时无需重复填写）
- API Key：向服务器管理员获取，使用 Bearer 鉴权
- 模型：

| 模型 ID | 引擎 | 输入 | 加速 |
|---|---|---|---|
| `h3-fl-base` | first_last | 文生视频、首帧、首尾帧 | 否（20 步） |
| `h3-fl-turbo` | first_last | 文生视频、首帧、首尾帧 | 是（6 步） |
| `h3-ref-base` | reference | 图片 / 视频 / 音频参考 | 否（20 步） |
| `h3-ref-turbo` | reference | 图片 / 视频 / 音频参考 | 是（6 步） |

## 能力边界

- 当前固定输出 720p，时长 4–15 秒，画幅支持 `9:16`、`16:9`、`1:1`。
- FL 与 Ref 的素材字段互斥：FL 只读取首帧/尾帧，Ref 只读取参考图、参考视频和参考音频。插件按所选模型自动组装，不会把 Ref 素材静默改写成首帧。
- Turbo 只改变采样步数与耗时，不承诺画面质量与 Base 完全一致。
- 任务可能长时间停留在 `queued`，这是引擎切换或 GPU 排队，不代表失败；请沿用同一任务 ID 等待结果，避免重复提交。
- 成片地址是带有效期的签名 URL，插件已声明结果地址为临时地址，宿主会及时转存。
